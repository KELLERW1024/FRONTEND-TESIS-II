Preguntas frecuentes

Todo lo que necesitas saber

¿La plataforma escribe todo mi proyecto automáticamente? +

La plataforma te guía mediante preguntas y utiliza tus respuestas para ayudarte a construir las diferentes secciones de tu proyecto. La idea es trabajar contigo, no simplemente generar un documento genérico.

¿Puedo guardar mi progreso y continuar después? +

Sí. Tus conversaciones, respuestas y progreso se almacenan en tu proyecto para que puedas continuar posteriormente.

¿Puedo subir imágenes, documentos o tablas? +

Sí. El sistema está preparado para trabajar con archivos, imágenes y datos relacionados con las respuestas de tu proyecto.

¿Puedo descargar mi proyecto? +

Según el plan contratado, podrás generar versiones de tu documento y exportarlas en formatos como PDF y Word.
